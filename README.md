# ITIN.com social media assets

Public media hosting for ITIN.com Instagram & LinkedIn carousels. These files exist so
Buffer's API can fetch them by public `raw.githubusercontent.com` URL when scheduling posts
(Buffer has no file-upload endpoint — media must be a public HTTPS URL).

Each folder is one carousel:
- `slide_01.png … slide_NN.png` — ordered Instagram carousel images (1080×1350)
- `carousel.pdf` — LinkedIn document/carousel post

No credentials or private data are stored here.
